# Game content

Everything the game is made of, sorted by kind. Each file starts with a comment that explains its fields.

- **items/**
  - weapons.js: guns and melee weapons
  - shop.js: trader supplies
  - loot.js: zombie drops and rarity
- **zombies/types.js:** every zombie type
- **characters/characters.js:** the 3D people used for each role
- **world/**
  - streets.js: street names and diagonals
  - landmarks.js: where landmark buildings stand
  - buildings/: one file per landmark building
  - building-themes.js: what is inside each kind of open building
  - furniture.js: furniture pieces
  - props.js: scanned street props

See ../MODDING.md to add your own content as a mod.
